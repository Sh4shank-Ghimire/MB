# 🌳 Tree Identification QR Code Project — DFO Kathmandu

This project was developed for the **Division Forest Office (DFO), Kathmandu**, to digitally document and share information about prominent tree species in the region using scannable QR codes. Over **50+ individual tree entries** were catalogued and linked to informational webpages via QR codes.

## 📌 Project Overview

- **Client**: Division Forest Office (DFO), Kathmandu
- **Scope**: Tree identification through QR-linked webpages
- **Total Trees Catalogued**: 50+
- **Technology Used**: 
  - Jekyll (static site generator)
  - HTML/CSS
  - Python (for automated page generation)
  - Pandas (data processing)
  - QR code generation libraries (`qrcode`, `Pillow`)

## 🧩 Features

- 🔗 Each tree has a **unique web page** generated from Excel data.
- 📸 Pages contain local and botanical names, DBH, height, GPS coordinates, family, and significance.
- 📱 Each page is linked via a **QR code**, placed physically on or near the tree for easy scanning.
- 🎨 Designed with a clean, mobile-friendly layout using a custom `baseurl.html` layout.
